# bbstrader.core

Shared utilities used across the rest of the package: the venue-neutral `Broker` execution
abstraction (with the in-memory `PaperBroker`), data structures/logging, and built-in vectorized
indicators (SMA, EMA, RSI, ATR, Bollinger Bands, MACD, z-score).
