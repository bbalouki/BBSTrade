# bbstrader.api

Handler injections that bridge the compiled C++ `MetaTraderClient` to a live MetaTrader 5
terminal via the Python `MetaTrader5` package.

!!! note
    The compiled `bbstrader.api.client` extension (`MetaTraderClient`, `TradeRequest`,
    `AccountInfo`, etc.) is documented in the [C++ API reference](/bbstrader/cpp/), since it
    has no Python source for this generator to introspect.

::: bbstrader.api
    options:
      show_submodules: true
